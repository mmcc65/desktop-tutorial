# Puppy Paw Windows Cursor Theme · Full v3

本目录是在已锁定的四张核心高清母版基础上扩展的完整第一版主题。核心母版没有重新生成：

- Normal：`../core-drafts/normal-high.png`
- Hover / Link：`../core-drafts/hover-high.png`
- Click：`../core-drafts/click-high.png`
- Drag / Move：`../core-drafts/drag-high.png`

## 成品

- `cursors/`：14 个静态 `.cur` 和 3 个动态 `.ani`
- `preview/overview-full.png`：完整状态总览图
- `preview/`：各状态单独预览图
- `Puppy-Paw-v3-Full.theme`：Windows 主题配置文件

## 状态映射

普通选择使用 Normal；链接选择使用 Hover；移动/拖拽使用 Drag；点击语义保留 Click 作为独立核心稿。文字输入保留清晰 I 型杆并配合小爪；后台工作和忙碌使用当前母版的轻微循环动作；调整大小和精确选择优先保证 Windows 功能识别。

## 安装

1. 将整个 `full-theme` 文件夹复制到不会被删除的位置。
2. 打开 Windows“设置 → 蓝牙和设备 → 鼠标 → 其他鼠标设置 → 指针”。
3. 按状态逐项点击“浏览”，选择 `cursors` 文件夹中的对应 `.cur` 或 `.ani`。
4. 点击“另存为”，命名为 `Puppy Paw v3 Full`，然后应用。

也可以尝试双击 `Puppy-Paw-v3-Full.theme`；如果 Windows 未自动解析相对路径，请使用上面的手动方式。
