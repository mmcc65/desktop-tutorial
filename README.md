# Puppy Paw Windows Cursor Theme

一套可实际安装使用的 Windows 小狗前爪鼠标指针主题。

## 项目特点

- 背面/上表面视角的小狗前爪，不使用肉垫、指甲或尖锐爪尖
- 灰、白、黑为主的毛茸茸卡通风格
- Normal、Hover、Click、Drag 四个核心状态使用同一高清母版做动作形变
- Click 保留张爪按下感，Drag 表现收紧抓取
- Text、Working、Busy、Unavailable、Resize、Precision 等系统状态已扩展
- 同时提供静态 `.cur` 与动态 `.ani` 文件
- 保留高清核心源图、单项预览图、完整总览图和主题配置

## 目录

- `core-drafts/`：四个核心状态的高清母图及对比图
- `full-theme/cursors/`：Windows `.cur` / `.ani` 成品
- `full-theme/preview/`：各状态预览及完整总览图
- `full-theme/Puppy-Paw-v3-Full.theme`：主题配置文件
- `full-theme/README/`：安装说明

## 安装使用

1. 下载或克隆本仓库。
2. 打开 `full-theme/cursors/`。
3. 进入 Windows“设置 → 蓝牙和设备 → 鼠标 → 其他鼠标设置 → 指针”。
4. 逐项点击“浏览”，选择对应的 `.cur` 或 `.ani` 文件。
5. 点击“另存为”，命名为 `Puppy Paw v3 Full`，然后应用。

也可以尝试双击 `full-theme/Puppy-Paw-v3-Full.theme`；若 Windows 未自动解析相对路径，请使用上述手动安装方式。
